# QRKot — благотворительный фонд поддержки котиков

QRKot — REST API-приложение благотворительного фонда, разработанное на FastAPI. Сервис предназначен для управления целевыми проектами по оказанию помощи кошкам и автоматического распределения поступающих пожертвований.

Фонд собирает средства на лечение животных, покупку корма, организацию приютов и другие благотворительные цели.

## Технологии

- Python 3.12
- FastAPI
- SQLAlchemy 2.0
- Pydantic 2
- SQLite
- aiosqlite
- Uvicorn
- Pytest

## Возможности приложения

**Целевые проекты**

- Создание благотворительных проектов.
- Просмотр списка всех проектов.
- Редактирование открытых проектов.
- Удаление проектов, в которые ещё не поступили средства.
- Автоматическое закрытие проекта после сбора необходимой суммы.

**Пожертвования**

- Создание пожертвований с необязательным комментарием.
- Просмотр списка пожертвований.
- Автоматическое распределение пожертвованных средств.
- Отслеживание распределённой суммы и статуса пожертвования.

## Алгоритм инвестирования

Пожертвования поступают в общий фонд, а не в конкретный проект.

Средства автоматически распределяются между открытыми проектами в порядке их создания — начиная с самого старого.

Если сумма пожертвования превышает необходимую для завершения текущего проекта, оставшиеся средства направляются в следующий открытый проект.

Если открытых проектов нет, нераспределённые средства сохраняются до создания нового проекта.

При достижении необходимой суммы проект закрывается автоматически. Аналогично пожертвование отмечается как полностью инвестированное после распределения всех его средств.

Создание проекта или пожертвования и последующее инвестирование выполняются в рамках одной транзакции базы данных.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd cat-charity-2
```

### 2. Создание виртуального окружения

```bash
python3.12 -m venv venv
```

Активация на macOS/Linux:

```bash
source venv/bin/activate
```

Активация на Windows:

```bash
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
uvicorn app.main:app --reload
```

Приложение будет доступно по адресу:

http://127.0.0.1:8000

Интерактивная документация Swagger UI:

http://127.0.0.1:8000/docs

Документация ReDoc:

http://127.0.0.1:8000/redoc

## База данных

Приложение использует асинхронное подключение к SQLite через SQLAlchemy и aiosqlite.

Адрес базы данных по умолчанию:

```text
sqlite+aiosqlite:///./fastapi.db
```

Конфигурация подключения находится в `app/core/config.py`.

## API-эндпоинты

### Целевые проекты

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/charity_project/` | Получение списка проектов |
| POST | `/charity_project/` | Создание проекта |
| PATCH | `/charity_project/{project_id}` | Редактирование проекта |
| DELETE | `/charity_project/{project_id}` | Удаление проекта |

### Пожертвования

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/donation/` | Получение списка пожертвований |
| POST | `/donation/` | Создание пожертвования |

### Пример создания проекта

**POST `/charity_project/`**

```json
{
  "name": "Помощь котятам",
  "description": "Сбор средств на лечение бездомных котят",
  "full_amount": 10000
}
```

### Пример создания пожертвования

**POST `/donation/`**

```json
{
  "full_amount": 1500,
  "comment": "На помощь котикам!"
}
```

## Тестирование

Для запуска автоматических тестов используется Pytest:

```bash
python -m pytest -v
```

Также API можно проверять вручную через Swagger UI или Postman.

## Архитектура

Приложение разделено на модули:

- `api/` — обработчики HTTP-запросов и валидаторы.
- `core/` — конфигурация приложения и подключение к базе данных.
- `models/` — ORM-модели SQLAlchemy.
- `schemas/` — Pydantic-схемы для валидации данных.
- `crud/` — операции с базой данных.
- `services/` — бизнес-логика автоматического инвестирования.

Такое разделение упрощает поддержку, тестирование и дальнейшее развитие приложения.
